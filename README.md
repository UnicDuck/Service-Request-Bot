# Service Request Bot

Telegram-бот для обработки заявок малого бизнеса.

Бот позволяет пользователю оставить заявку, сохраняет её в SQLite-базу данных, отправляет уведомление в Telegram-группу администраторов и позволяет менять статус заявки через inline-кнопки.

## Возможности

- Главное меню в Telegram
- Создание заявки пользователем
- Отправка заявки в группу администраторов
- Сохранение заявок в SQLite
- Просмотр пользователем своих последних заявок
- Изменение статуса заявки через кнопки
- Проверка прав администратора
- Команда `/help`
- Обработка ошибок при создании заявки

## Как это работает

Пользователь открывает бота и нажимает **Оставить заявку**.

После этого бот просит описать задачу.  
Когда пользователь отправляет текст, бот:

1. сохраняет заявку в базу данных;
2. присваивает ей номер;
3. отправляет заявку в Telegram-группу;
4. показывает пользователю сообщение об успешной отправке.

Администратор может изменить статус заявки прямо из Telegram-группы:

- 🟡 В работе
- ✅ Выполнено
- ❌ Отменено

Пользователь может нажать **Мои заявки** и увидеть последние заявки со статусами.
